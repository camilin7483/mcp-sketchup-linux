# Historial de cambios

## [0.1.0] - 2026-11-18

- Publicación del servidor MCP por stdio y la extensión Ruby instalable `.rbz`.
- Modo simulado persistente para crear, transformar, aplicar materiales, eliminar y exportar escenas desde Linux.
- Lanzador Wine para la instalación local de SketchUp Make 2017 con un prefijo separado.
- Guía de conexión con OpenCode y alcance por modo de funcionamiento.
